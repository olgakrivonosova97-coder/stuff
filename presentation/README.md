# НЕЙРОПИЛОТ — презентация (локальный проект)

Локальное развёртывание презентации «НЕЙРОПИЛОТ — СКУАД / ФНС России»
(к 14.07.2026) в виде простого редактируемого статического проекта
HTML / CSS / JS. Внешний вид, стили, анимации, шрифты и поведение
сохранены точь-в-точь как в исходном HTML-файле.

## Структура проекта

```
presentation/
├── index.html                 # разметка слайдов (весь текст здесь)
├── styles.css                 # все стили презентации
├── script.js                  # навигация, прогресс-бар, reveal-анимации
└── assets/
    ├── fonts/                 # шрифт Inter (локально) + inter.css
    │   ├── inter.css
    │   └── inter-*-normal.woff2
    └── fontawesome/           # иконки Font Awesome 6.4.0 (локально)
        ├── css/all.min.css
        └── webfonts/
```

## Как запустить

Проекту нужен любой локальный веб-сервер (шрифты и иконки не грузятся
по протоколу `file://` из-за политики CORS браузера).

Самый простой способ — Python (есть почти везде):

```bash
cd presentation
python3 -m http.server 8000
```

Затем откройте в браузере: <http://localhost:8000/>

Альтернативы:

```bash
npx serve .        # Node.js
php -S localhost:8000
```

## Навигация по презентации

- Стрелки **↑ / ↓**, **PageUp / PageDown**, **пробел** — листать слайды
- **Home / End** — первый / последний слайд
- Точки справа — переход к конкретному слайду
- Кнопки-стрелки внизу по центру — назад / вперёд
- Прогресс-бар сверху отражает прокрутку

## Где что редактировать

- **Текст слайдов** — `index.html`. Каждый слайд — это
  `<section class="slide" id="slide-...">`. Меняйте текст прямо внутри.
- **Стили** (цвета, отступы, шрифты, размеры) — `styles.css`.
  Основная палитра задаётся CSS-переменными в блоке `:root` в начале файла.
- **Поведение / анимации** (навигация, прогресс-бар, reveal) — `script.js`.

## Подключённые ресурсы

Всё подключается **локально**, интернет для показа не нужен:

- Шрифт **Inter** (веса 300–900, подмножества latin + cyrillic) —
  `assets/fonts/` (изначально в исходнике грузился с Google Fonts CDN).
- **Font Awesome 6.4.0** — `assets/fontawesome/`
  (изначально в исходнике грузился с jsDelivr CDN).

Внешних (CDN) зависимостей не осталось.
