## 6. Локальный запуск

Нужен любой локальный веб-сервер (шрифты и иконки не грузятся по `file://`):

```bash
cd presentation
python3 -m http.server 8000
```

Открыть: <http://localhost:8000/>

Навигация: стрелки ↑/↓, PageUp/PageDown, пробел, Home/End; точки справа; кнопки
внизу по центру; прогресс-бар сверху.
